# 🎮 Creeper

یک بازی ۲بعدی داستان‌محور با **C#** و **MonoGame** (DesktopGL) — بدون موتور بازی آماده، همه‌چیز سورس‌نویسی شده.

## ✨ ویژگی‌ها

- 🖥️ تمام صفحه‌ی borderless (با `F11` قابل تعویض)
- 🎨 صفحه‌ی intro با fade-in و متن چشمک‌زن
- 🔀 ترنزیشن نرم: fade-out تصویر اول + fade-in تصویر منو
- 🎵 موزیک پس‌زمینه‌ی لوپ‌شونده + افکت صوتی کلیک
- 🔤 پشتیبانی از فونت TrueType دلخواه (`.ttf`/`.otf`) با fallback به فونت پیکسلی داخلی
- 💾 سه اسلات ذخیره (فایل سلکت به سبک Undertale)
- 🎬 پخش ویدیوی اوپنینگ هنگام شروع بازی جدید
- ⌨️ کنترل کامل با کیبورد، نشانگر موس مخفی
- 🔁 تبدیل خودکار فرمت‌های تصویر و صوت پشتیبانی‌نشده

## 🚀 اجرا

نیازمندی: **.NET 8 SDK**

```bash
dotnet restore
dotnet run
```

در حالت `Debug` پنجره‌ی کنسول باز می‌ماند تا لاگ لود شدن asset‌ها دیده شود.
برای خروجی تمیز بدون کنسول:

```bash
dotnet run -c Release
```

## 📦 فایل‌های رسانه‌ای

فایل‌ها را در پوشه‌ی `assets/` بگذارید. پسوند مهم نیست — به‌صورت خودکار تبدیل می‌شوند:

| نام پایه | کاربرد | فرمت‌های قابل قبول |
|---|---|---|
| `image` | تصویر صفحه‌ی intro | `png`, `bmp`, `jpg`, `jpeg`, `gif`, `tga`, `webp`, `tif` |
| `negro` | تصویر منوی اصلی (تمام صفحه) | همان بالا |
| `untrust` | موزیک پس‌زمینه | `wav`, `mp3`, `m4a`, `aac`, `wma`, `flac`, `aiff`, `ogg` |
| `click` | افکت صوتی منو | همان بالا |
| `Fenglish` | فونت متن‌های بازی | `ttf`, `otf` |
| `opening` | ویدیوی اوپنینگ | `mp4`, `mkv`, `webm`, `mov`, `avi`, `m4v`, `wmv` |

**ویدیوی اوپنینگ**

فایل ویدیو را با نام `opening` (یا `intro`, `cutscene`) در `assets/` بگذارید.

> ⚠️ **نیازمند ffmpeg:** بک‌اند DesktopGL در MonoGame اصلاً کلاس `VideoPlayer` ندارد، برای همین ویدیو از طریق `ffmpeg` دیکود می‌شود. `ffmpeg.exe` را در پوشه‌ی `assets/` (یا کنار فایل اجرایی، یا در PATH سیستم) قرار دهید.
>
> اگر ffmpeg نصب نباشد بازی کرش نمی‌کند — فقط ویدیو رد می‌شود و مستقیم به صفحه‌ی COMING SOON می‌رود.

**فونت چطور انتخاب می‌شود؟**

اولین `.ttf` یا `.otf` موجود در `assets/` به‌صورت خودکار لود می‌شود. اگر چند فایل باشد، اولویت با نام‌های `fenglish`, `font`, `main` است. اگر هیچ فونتی نباشد، بازی به فونت پیکسلی داخلی (`PixelFont.cs`) برمی‌گردد و باز هم اجرا می‌شود.

**تبدیل خودکار چطور کار می‌کند؟**

- `ImageConverter` تصاویر پرریسک (مثل JPEG‌های progressive یا CMYK) را با ImageSharp دوباره به PNG ۳۲بیتی encode می‌کند.
- `AudioConverter` هر چیزی جز WAV را با NAudio به WAV استریوی ۴۴٫۱kHz/۱۶bit تبدیل می‌کند (چون بک‌اند DesktopGL فقط WAV را decode می‌کند).
- نتیجه با پسوند `_converted` کنار فایل اصلی cache می‌شود و فقط وقتی فایل مبدأ تغییر کند دوباره ساخته می‌شود.

## 🎮 کنترل‌ها

| صفحه | کلید | کار |
|---|---|---|
| Intro | هر کلیدی | رفتن به منوی اصلی |
| منوی اصلی | `↑` `↓` یا `W` `S` | جابه‌جایی بین گزینه‌ها |
| منوی اصلی | `Enter` / `Space` / `Z` | انتخاب |
| منوی اصلی | `Esc` | خروج |
| فایل سلکت | `↑` `↓` | انتخاب اسلات |
| فایل سلکت | `Enter` | شروع / ادامه |
| فایل سلکت | `Delete` | پاک کردن اسلات |
| ویدیوی اوپنینگ | هر کلیدی | رد کردن |
| Options | `←` `→` | تغییر مقدار (صدا، fullscreen) |
| Options | `Esc` | بازگشت |
| همه‌جا | `F11` | تعویض fullscreen / پنجره‌ای |

## 📁 ساختار پروژه

```
creeper/
├── CreeperGame.csproj   # پروژه و پکیج‌ها
├── Program.cs           # نقطه‌ی ورود + گزارش کرش
├── Game1.cs             # حلقه‌ی بازی، state machine، رندر
├── SaveSlots.cs         # سه اسلات ذخیره (فایل متنی ساده)
├── VideoPlayback.cs     # پخش ویدیو با پایپ کردن فریم‌های ffmpeg
├── FFmpeg.cs            # پیدا کردن ffmpeg و استخراج صدای ویدیو
├── TextRenderer.cs      # لایه‌ی متن: TTF با FontStashSharp + fallback
├── PixelFont.cs         # فونت بیت‌مپ ۶×۷ (fallback داخلی)
├── ImageConverter.cs    # تبدیل تصویر → PNG
├── AudioConverter.cs    # تبدیل صوت → WAV
└── assets/              # تصاویر و صداها
```

## 🎯 وضعیت منو

- **PLAY** — فایل سلکت با سه اسلات:
  - اسلات **خالی** → ویدیوی اوپنینگ پخش می‌شود، بعد صفحه‌ی COMING SOON
  - اسلات **پر** → مستقیم صفحه‌ی COMING SOON
- **OPTIONS** — فعال (تنظیم صدا و fullscreen)
- **EXIT** — فعال

## 🛠️ تکنولوژی

- **C#** روی **.NET 8**
- **MonoGame.Framework.DesktopGL** — همان فریمورکی که Stardew Valley و Celeste با آن ساخته شده‌اند
- **FontStashSharp** — رندر فونت TrueType
- **NAudio** — تبدیل صوت
- **SixLabors.ImageSharp** — تبدیل تصویر
