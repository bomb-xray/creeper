# 🎮 Creeper Game

یک بازی 2D ساخته شده با **C#** و **Raylib-cs**

## ✨ ویژگی‌ها

- 🖥️ تمام صفحه (Fullscreen)
- 🎨 نمایش تصاویر با افکت Fade In/Out
- 🎵 پخش موزیک پس‌زمینه
- 🔊 افکت صوتی کلیک
- ⌨️ کنترل کامل با کیبورد
- 🚫 مخفی شدن نشانگر موس
- 🎯 منوی اصلی با گزینه‌های Play, Options, Exit
- 🔤 متن‌های پیکسلی

## 🚀 نحوه اجرا

### پیش‌نیازها

- **.NET 8 SDK** یا بالاتر
- **Raylib** (به صورت خودکار از NuGet نصب می‌شود)

### مراحل اجرا

1. فایل‌های رسانه‌ای خود را در پوشه `assets/` قرار دهید:
   - `image.png` - تصویر صفحه شروع (Intro)
   - `negro.png` - تصویر منوی اصلی
   - `untrust.mp3` - موزیک پس‌زمینه (یا `untrust.wav`)
   - `click.wav` - افکت صوتی کلیک (پیش‌فرض موجود است)

2. بازی را اجرا کنید:

```bash
dotnet restore
dotnet run
```

## 🎮 کنترل‌ها

### صفحه شروع (Intro)
- **هر کلیدی** - ادامه به منوی اصلی

### منوی اصلی
- **↑ / ↓** یا **W / S** - حرکت بین گزینه‌ها
- **Enter** یا **Space** - انتخاب گزینه
- **ESC** - خروج

### صفحه Options
- **↑ / ↓** یا **W / S** - حرکت بین گزینه‌ها
- **Enter** یا **Space** - انتخاب
- **ESC** - بازگشت
